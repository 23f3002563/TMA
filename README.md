# Trekking Management Application (TMA)

## Project Overview

The Trekking Management Application is a web-based system developed using Flask. It allows users to explore and book treks, while administrators manage treks, bookings, staff, and users.

## Features

### Admin
- Admin Login
- Dashboard
- Add, Edit and Delete Treks
- Manage Users
- Manage Staff
- View Bookings

### Staff
- Staff Login
- View Assigned Treks
- View Participants
- Update Trek Status
- Profile Page

### User
- User Registration & Login
- View Available Treks
- Book Treks
- View My Bookings
- Profile Page

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- Jinja2

## Installation

1. Clone the repository

```bash
git clone https://github.com/23f3002563/TMA.git
```

2. Create Virtual Environment

```bash
python -m venv venv
```

3. Activate Virtual Environment

```bash
venv\Scripts\activate
```

4. Install Dependencies

```bash
pip install -r requirements.txt
```

5. Run the project

```bash
python run.py
```
